## 📊 Dataset Schema

The full dataset is available in [`router-passwords.json`](./router-passwords.json). Each model entry contains:

```json
{
  "brand": "TP-Link",
  "model": "Archer AX55 (AX3000)",
  "ip": "192.168.0.1",
  "username": "admin",
  "password": "(setup created)",
  "status": "Setup Created"
}
```
